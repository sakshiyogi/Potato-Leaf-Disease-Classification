
# LeafLens — Streamlit Potato Leaf Classifier

A single-page Streamlit interface for your trained CNN model. The UI uses a soft cream and green theme.

## Project folder structure

```text
LeafLens_Streamlit_Project/
│
├── app.py
├── requirements.txt
├── README.md
├── .gitignore
│
└── model/
    ├── potato_cnn_model.keras
    └── classification_report.txt
```

## 1. Add your trained model files

Copy the two files you already saved from your notebook into the `model` folder:

- `potato_cnn_model.keras`
- `classification_report.txt`

**Important:** In the notebook you uploaded, `classification_report.txt` is written using:

```python
Path("classification_report.txt").write_text("\n".join(class_names), encoding="utf-8")
```

So this file contains the class names, one class per line. It is not a scikit-learn precision/recall/F1 report. Keep the class order exactly as generated by `train_ds.class_names`.

## 2. Open the project in VS Code

Extract the ZIP file, then open the `LeafLens_Streamlit_Project` folder in VS Code.

## 3. Create and activate a virtual environment (Windows)

Open the VS Code terminal in the project folder and run:

```powershell
python -m venv venv
.\venv\Scripts\activate
```

If PowerShell blocks activation, run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

## 4. Install libraries

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

TensorFlow installation can take a few minutes. Use a Python version supported by the TensorFlow version installed in your environment (Python 3.10 or 3.11 is a practical choice for this requirements range).

## 5. Run the app

```bash
streamlit run app.py
```

Streamlit will show a local URL, usually `http://localhost:8501`. Open it in your browser.

## How preprocessing matches your notebook

Your notebook creates RGB images at `128 × 128`, and your model begins with:

```python
tf.keras.layers.Rescaling(1.0/255)
```

The app therefore:
1. Converts uploaded images to RGB.
2. Resizes them to `128 × 128`.
3. Sends float32 pixel values in the original 0–255 range to the model.

Do **not** divide by 255 again in `app.py`, because the model already contains the Rescaling layer. Data augmentation in the model is automatically inactive during prediction (`training=False`).

## Common issues

### `FileNotFoundError` for the model
Check that the model is named exactly `potato_cnn_model.keras` and is inside the `model` folder.

### Class count does not match model output
Check that `classification_report.txt` has exactly one class name per line and in the same order as `train_ds.class_names` from training.

### TensorFlow installation fails
Check your Python version and use a fresh virtual environment. Avoid installing packages into a different Python environment from the one used to run Streamlit.

### App starts but prediction fails
Confirm that the model file is the same trained model from the notebook and that it accepts an input shape of `(128, 128, 3)`.

## Note
The confidence score is the model's softmax output, not a guarantee of diagnostic accuracy. This project is intended as an educational CNN demonstration.
